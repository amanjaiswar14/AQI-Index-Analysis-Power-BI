# 🌍 AQI Index Analysis Dashboard

## 📌 Project Overview
The **AQI Index Analysis Dashboard** is an interactive data visualization project designed to analyze and monitor **Air Quality Index (AQI)** levels across Indian states and cities. The dashboard helps users understand pollution severity, identify dominant pollutants, and observe AQI trends over time for informed environmental and public health insights.

---

## 🎯 Project Objectives
- Monitor AQI levels by **State, City, and Year**
- Identify **primary pollutants** contributing to poor air quality
- Classify AQI based on **standard AQI categories**
- Analyze **historical AQI trends** over time

---

## 🛠️ Tech Stack
-  **Power BI** – Data visualization & dashboard development  
-  **Microsoft Excel / CSV** – Data source  
- **DAX (Data Analysis Expressions)** 
- **Power Query** – Data cleaning and transformation 
-  **Bing Maps** – Geographic sales visualization 

---

## 📊 Data Source
- Public Air Quality datasets
- Pollutants: PM10, PM2.5, CO, NO₂, O₃

---

## ✨ Features & Highlights
- Interactive filters (Year, State, Area)
- KPI cards (Avg AQI, Max AQI, Primary Pollutant)
- City-wise AQI ranking
- AQI trend over time
- AQI category distribution
- Pollutant occurrence frequency
- Map-based visualization
